## 🚀 Про проєкт

Metodist — це AI-сервіс для створення конспектів уроків та навчальних матеріалів.

Сервіс допомагає вчителям швидше формувати структуру уроку, генерувати DOCX-конспекти та працювати з власними навчальними матеріалами.

> 💡 Основна мета Metodist — економити час вчителя, а не замінювати його.

---

## ⚙️ Можливості

- 📄 генерація конспектів уроків у DOCX
- 🧠 AI-аналіз навчальних матеріалів
- 📚 підтримка DOCX та PPTX файлів
- ✏️ автоматичне формування структури уроку
- 🏫 вибір предмету та класу
- ⏱ автоматизація рутинної роботи вчителя

---

## 🧠 Як працює Metodist

Metodist не просто генерує текст.

Сервіс:
- аналізує завантажені матеріали
- використовує методичні приклади
- формує структуру уроку
- створює готовий DOCX-документ для редагування

---

## 📄 Що отримує користувач

Після генерації користувач отримує готовий конспект уроку, який містить:

- 🎯 мету уроку
- 📚 структуру заняття
- 👩‍🏫 діяльність вчителя
- 👨‍🎓 діяльність учнів
- ✍️ вправи та завдання
- 📌 пояснення матеріалу

---

## ⚠️ Поточний статус

> Проєкт знаходиться у стадії Alpha v0.8

На даний момент сервіс найкраще працює для 3–4 класів.

Для 1–2 класів модель ще активно доопрацьовується:
- покращується структура уроків
- оптимізується логіка генерації
- підвищується відповідність НУШ

Можливі:
- помилки
- неточності
- нестабільна генерація
