# Методист AI

Сучасний AI-помічник для вчителів та освітян.

## Можливості

- Генерація конспектів уроків
- Створення тестів
- Формування навчальних матеріалів
- AI-допомога для педагогів
- Автоматизація рутинних задач

## Технології

### Frontend

- Next.js
- React
- TailwindCSS

### Backend

- FastAPI
- Python

## Запуск проєкту

### Frontend

```bash
npm install
npm run dev
```

### Backend

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

## Статус

Проєкт знаходиться у стадії активної розробки.
